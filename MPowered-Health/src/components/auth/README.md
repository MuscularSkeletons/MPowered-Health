# Account UI

`auth-ui.tsx` has the header, fields, buttons and layout used by sign-in,
sign-up and onboarding. Their styles are in the same file. `sectionLabel`
is the small label above a heading, like “YOUR PROFILE”.

The `welcome` folder is for the opening splash pages. `styles.ts` controls
the text, dots and buttons. `artwork.tsx` displays the two screen previews
and keeps their frame styles together.

Shared colours are in `src/constants/profile/ui.ts`. The loading screen's M
and the app icon use the same green as “Health” in the header. The activation
screen uses the yellow paper plane from `assets/images/onboarding-launch.png`.
